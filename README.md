# المأثر — نظام تحضير العمال والحسابات

نسخة PWA قابلة للتثبيت على الهاتف، مبنية على ملف التطبيق المرفق.

## الوظائف الموجودة
- إدارة العمال والمهن والأجرة اليومية.
- تسجيل حضور: يوم كامل، نصف يوم، وإدخال مخصص.
- تسجيل السلف والمسحوبات وخصمها من المستحق.
- حساب إجمالي الأيام والمستحق والمسحوبات والصافي.
- البحث والتصفية حسب المهنة.
- كشف حساب نصي ومشاركة عبر WhatsApp.
- تصدير كشف حساب PDF.
- تحويل SAR/YER.
- تسجيل الدخول بالبريد أو Google عند توفير إعدادات Firebase الصحيحة.
- وضع تجربة محلي.
- حفظ بيانات وضع التجربة محلياً على الجهاز.
- PWA للتثبيت على الهاتف والعمل مع Service Worker.

## تشغيل
يفضل تشغيله عبر خادم محلي/استضافة HTTPS حتى تعمل PWA وService Worker بشكل صحيح.
يمكن فتح `index.html` مباشرة للمعاينة، لكن التثبيت والعمل الكامل دون اتصال يحتاجان استضافة عبر HTTP/HTTPS.

## Firebase
الملف الأصلي يحتوي إعداد Firebase تجريبي/احتياطي. لتفعيل الحسابات والمزامنة السحابية يجب استبداله بإعدادات مشروع Firebase حقيقي وتفعيل Authentication وFirestore.
